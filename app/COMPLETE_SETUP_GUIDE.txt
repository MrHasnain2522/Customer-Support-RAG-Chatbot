## 🚀 Installation Steps

### Method 1: Automated Setup (Recommended)

```bash
cd backend
chmod +x setup.sh
./setup.sh
```

### Method 2: Manual Setup

```bash
# 1. Navigate to backend directory
cd backend

# 2. Create virtual environment
python3 -m venv venv

# 3. Activate virtual environment
# On Linux/Mac:
source venv/bin/activate
# On Windows:
# venv\Scripts\activate

# 4. Upgrade pip
pip install --upgrade pip

# 5. Install dependencies
pip install -r requirements.txt

# 6. Create environment file
cp .env.example .env

# 7. Edit .env with your settings
nano .env  # or use any text editor

# 8. Initialize database
python -c "from app.db.init_db import init_database; init_database()"
```

## ⚙️ Configuration

Edit the `.env` file:

```env
# Flask Configuration
FLASK_APP=app.main:app
FLASK_ENV=development
SECRET_KEY=your-secret-key-change-this

# Database
DATABASE_URL=sqlite:///instance/app.db

# API Keys (Optional - for AI features)
OPENAI_API_KEY=sk-your-openai-key
ANTHROPIC_API_KEY=sk-ant-your-anthropic-key

# RAG Configuration
EMBEDDING_MODEL=sentence-transformers/all-MiniLM-L6-v2
MAX_CONTEXT_LENGTH=4000

# Server
HOST=0.0.0.0
PORT=5000
DEBUG=True
```

## 🐳 Docker Deployment

### Build Image

```bash
docker build -t backend-api .
```

### Run Container

```bash
docker run -p 5000:5000 \
  -e OPENAI_API_KEY=your-key \
  -e ANTHROPIC_API_KEY=your-key \
  -v $(pwd)/instance:/app/instance \
  backend-api
```

### Using Docker Compose

Create `docker-compose.yml`:

```yaml
version: '3.8'
services:
  backend:
    build: .
    ports:
      - "5000:5000"
    environment:
      - FLASK_ENV=production
      - DATABASE_URL=sqlite:///instance/app.db
      - SECRET_KEY=your-secret-key
    volumes:
      - ./instance:/app/instance
```

Run:
```bash
docker-compose up -d
```

## 📊 Database Schema

### Users Table
```sql
CREATE TABLE users (
    id INTEGER PRIMARY KEY,
    user_id VARCHAR(100) UNIQUE NOT NULL,
    username VARCHAR(100),
    email VARCHAR(120),
    created_at DATETIME NOT NULL,
    updated_at DATETIME
);
```

### Conversations Table
```sql
CREATE TABLE conversations (
    id INTEGER PRIMARY KEY,
    conversation_id VARCHAR(100) UNIQUE NOT NULL,
    user_id INTEGER NOT NULL,
    title VARCHAR(200),
    created_at DATETIME NOT NULL,
    updated_at DATETIME,
    is_active BOOLEAN,
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

### Messages Table
```sql
CREATE TABLE messages (
    id INTEGER PRIMARY KEY,
    conversation_id INTEGER NOT NULL,
    user_id INTEGER NOT NULL,
    role VARCHAR(20) NOT NULL,
    content TEXT NOT NULL,
    created_at DATETIME NOT NULL,
    context_used TEXT,
    embedding BLOB,
    FOREIGN KEY (conversation_id) REFERENCES conversations(id),
    FOREIGN KEY (user_id) REFERENCES users(id)
);
```

### Greetings Table
```sql
CREATE TABLE greetings (
    id INTEGER PRIMARY KEY,
    text VARCHAR(200) NOT NULL,
    language VARCHAR(10),
    category VARCHAR(50),
    created_at DATETIME NOT NULL,
    is_active BOOLEAN
);
```

## 🔧 Customization Guide

### Adding a New API Endpoint

1. Create route in `app/api/`:
```python
# app/api/new_routes.py
from flask import Blueprint

new_bp = Blueprint('new', __name__)

@new_bp.route('/new-endpoint', methods=['GET'])
def new_endpoint():
    return {'message': 'Hello!'}
```

2. Register blueprint in `app/__init__.py`:
```python
from app.api.new_routes import new_bp
app.register_blueprint(new_bp, url_prefix='/api')
```

### Adding a New Database Model

1. Create model in `app/models/`:
```python
# app/models/new_model.py
from app import db
from datetime import datetime

class NewModel(db.Model):
    __tablename__ = 'new_models'
    
    id = db.Column(db.Integer, primary_key=True)
    name = db.Column(db.String(100), nullable=False)
    created_at = db.Column(db.DateTime, default=datetime.utcnow)
```

2. Import in `app/models/__init__.py`:
```python
from app.models.new_model import NewModel
```

3. Recreate database:
```bash
rm instance/app.db
python -c "from app.db.init_db import init_database; init_database()"
```

## 🐛 Troubleshooting

### Issue: Module not found
**Solution:**
```bash
source venv/bin/activate
pip install -r requirements.txt
```

### Issue: Database locked
**Solution:**
```bash
# Stop all running instances
# Then reset database
rm instance/app.db
python -c "from app.db.init_db import init_database; init_database()"
```

### Issue: Port already in use
**Solution:**
```bash
# Change port in .env
PORT=5001

# Or find and kill process
lsof -ti:5000 | xargs kill -9
```

### Issue: SQLite version too old
**Solution:**
```bash
# Upgrade Python and recreate virtual environment
python3 --version  # Should be 3.8+
```
